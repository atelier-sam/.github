## L'Atelier de Sam

Repair workshop in Poitiers, France. The tools we write for our own work end up here, free and open source.

Atelier de réparation à Poitiers. Les outils écrits pour l'atelier sont publiés ici, libres.

| Project | What it does |
|---|---|
| [Vespry](https://github.com/atelier-sam/vespry) | Keep your Discord history: exports that resume where they stopped, from your own Discord tab, at a human pace. JSON, HTML, CSV, TXT. 100% local. Chrome, Edge, Firefox. |
| [iCrashDiag](https://github.com/atelier-sam/iCrashDiag) | Native macOS app that reads iPhone crash logs, built for repair technicians. |

Found a bug? Open an issue on the project. Have an idea? Start a discussion.
